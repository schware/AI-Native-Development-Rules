## 사용 규칙
- 먼저 해당 작업과 직접 관련된 문서만 읽습니다.
- 상세 근거는 각 문서 마지막의 참고 문서에서 확인합니다.
- 미확정 사항을 사실로 채우지 말고 질문 또는 가정으로 표시합니다.
